# trtrx

Direct-to-consumer testosterone replacement therapy site. Frontend-only marketing site preparing for clinic launch.

## Stack

- Next.js 14 (Pages Router) + TypeScript strict
- Tailwind CSS with HSL theme tokens
- shadcn/ui primitives (six only)
- Fraunces (display) + Inter (UI) + JetBrains Mono (data) via Google Fonts
- Vercel deploy with ISR

## Develop

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build && npm start
```
